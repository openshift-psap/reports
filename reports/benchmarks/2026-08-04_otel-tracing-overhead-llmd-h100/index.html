Why Zero Overhead

vLLM's OpenTelemetry integration uses async, non-blocking export. Trace spans are:

  • Created in-memory with minimal allocation (span name + attributes)
  • Batched by the OpenTelemetry SDK's BatchSpanProcessor
  • Exported in background threads via gRPC to the OTel Collector
  • Never on the inference hot path — token generation is not blocked by span export

Recommendation: Enable tracing by default in all benchmark and production runs. The per-request routing attribution, latency breakdown, and worker distribution data far outweighs the zero measurable cost.
