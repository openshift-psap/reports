OpenSM on ConnectX-8 (CX8/XDR) — GB200 NVL4 Bring-Up

Investigation · 2026-08-03 · Thameem Abbas
gb200 cx8 opensm infiniband xdr

Problem

ConnectX-8 (MT4131) IB ports visible but OpenSM cannot bind. Inbox OpenSM 3.3.24 (RHEL 9) fails with ERR 5426: Unable to register class 129 version 1. Physical ports stuck in Polling state.

Root Causes

  1. Missing IB kernel modules — kernel-64k-modules-extra not installed (contains mlx5_ib, ib_core, ib_umad)
  2. CX8/XDR requires SMI devices — new requirement for multi-plane support. OpenSM must bind to an SMI virtual device, not directly to mlx5_X
  3. Inbox OpenSM 3.3.24 not CX8-aware — always picks mlx5_0 first, fails. Need DOCA-OFED's OpenSM 5.27.1+

Environment

NodeGB200 NVL4 Archaarch64 OSRHEL 9.8 Kernel5.14.0-687.24.1.el9_8.aarch64+64k NICs4× ConnectX-8 (MT4131), FW 40.47.1026 CablesNVIDIA OSFP XDR optical (980-9IAT0-00XM00), 1310nm, 500m SMF

Steps

1

Install IB kernel modules

For 64k page size kernel, install the matching kernel-64k-modules-extra:

sudo dnf install kernel-64k-modules-extra-$(uname -r | sed 's/+64k//') -y
sudo modprobe mlx5_ib

For standard 4k kernel:

sudo dnf install kernel-modules-extra-$(uname -r) -y
sudo modprobe mlx5_ib

Verify:

ibstat  # should show mlx5_0, mlx5_1, etc.
lsmod | grep mlx5_ib
ls /dev/infiniband/  # umad0, uverbs0, etc.
2

Install DOCA-OFED

Note: MLNX_OFED does NOT support CX8 — ConnectX-7 was the last generation. Must use DOCA-OFED.
# Add DOCA repo
sudo bash -c 'cat > /etc/yum.repos.d/doca.repo << EOF
[doca]
name=NVIDIA DOCA-OFED Repository
baseurl=https://linux.mellanox.com/public/repo/doca/latest/rhel9/arm64-sbsa/
enabled=1
gpgcheck=0
EOF'

# For x86_64, use:
# baseurl=https://linux.mellanox.com/public/repo/doca/latest/rhel9/x86_64/

sudo dnf makecache
sudo systemctl stop opensm 2>/dev/null
sudo dnf install doca-ofed -y

Key packages installed:

  • opensm-5.27.1 — CX8/XDR-aware subnet manager
  • mft — Mellanox Firmware Tools (mlxlink, mlxconfig, flint)
  • mlnx-iproute2 — MOFED rdma tool with SMI support
  • perftest — ib_write_bw, ib_read_bw, etc.
  • mlnx-ofa_kernel-dkms — DKMS kernel modules
  • ucx — unified communication framework
3

Create SMI devices

CX8/XDR requires SMI (Subnet Management Interface) virtual devices for OpenSM binding. This is the key CX8-specific step.

# Create SMI device for each CX8 port
sudo rdma dev add smi0 type SMI parent mlx5_0
sudo rdma dev add smi1 type SMI parent mlx5_1
sudo rdma dev add smi2 type SMI parent mlx5_2
sudo rdma dev add smi3 type SMI parent mlx5_3

# Verify
rdma dev show
# Should show smi0..smi3 with type=smi parent=mlx5_X

Each SMI device exposes 4 ports (multi-plane). New UMAD devices appear in /dev/infiniband/ (umad4+, issm4+).

Important: SMI devices do not persist across reboot. Create a systemd service to recreate them on boot:
sudo bash -c 'cat > /etc/systemd/system/create-smi-devices.service << EOF
[Unit]
Description=Create SMI devices for CX8 IB ports
After=rdma.service
Before=opensmd.service

[Service]
Type=oneshot
ExecStart=/usr/sbin/rdma dev add smi0 type SMI parent mlx5_0
ExecStart=/usr/sbin/rdma dev add smi1 type SMI parent mlx5_1
ExecStart=/usr/sbin/rdma dev add smi2 type SMI parent mlx5_2
ExecStart=/usr/sbin/rdma dev add smi3 type SMI parent mlx5_3
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target
EOF'
sudo systemctl daemon-reload
sudo systemctl enable create-smi-devices.service
4

Start OpenSM

Note: DOCA-OFED's service name is opensmd (not opensm).
sudo systemctl enable opensmd
sudo systemctl start opensmd

# Verify binding
tail -20 /var/log/opensm.log
# Should show: "osm_sm_bind: Bind to port guid ... as main SM port"
# Followed by: "HEAVY SWEEP START"
5

Diagnose physical link (if needed)

# Start MST for firmware-level tools
sudo mst start

# Check link status per port
sudo mlxlink -d mlx5_0

# Check cable/transceiver module info
sudo mlxlink -d mlx5_0 -m

# Key fields to check:
# - State: should be "Active" (not "Signal detect" or "Polling")
# - Rx Power: should be > -10 dBm (not -40 dBm = no light)
# - Enabled Link Speed: XDR (0x100)
# - Troubleshooting: Status Opcode 0 = no issue
6

Verify fabric connectivity

Once physical links are up and OpenSM assigns LIDs:

ibstat                    # State: Active, Physical: LinkUp
ibnetdiscover             # Full fabric topology
ibnodes                   # All nodes
sminfo                    # SM status
ibping -L <remote_lid>    # Ping by LID

# RDMA bandwidth test
# Server side:
ib_write_bw -d mlx5_0 --report_gbits
# Client side:
ib_write_bw -d mlx5_0 <server_ip> --report_gbits

OCP Pod Reproduction

To run OpenSM from a pod on OCP with CX8 IB ports:

Prerequisites

  • Node must have CX8 IB HCAs
  • DRA or device plugin exposing IB devices to pods
  • Pod needs privileged SCC or specific capabilities

Pod requirements

securityContext:
  privileged: true    # needed for UMAD access and SMI device creation
  # OR granular:
  capabilities:
    add:
      - IPC_LOCK
      - NET_ADMIN
      - SYS_ADMIN    # for rdma dev add

Container image needs

  • rdma-core — for rdma tool, ibstat, ibnetdiscover
  • opensm 5.27+ — from DOCA-OFED repo, NOT inbox RHEL
  • infiniband-diags — for sminfo, smpquery, perfquery
  • mft — optional, for mlxlink diagnostics

Volume mounts

volumeMounts:
  - name: infiniband
    mountPath: /dev/infiniband
  - name: sysfs
    mountPath: /sys
volumes:
  - name: infiniband
    hostPath:
      path: /dev/infiniband
  - name: sysfs
    hostPath:
      path: /sys

Init container or entrypoint script

#!/bin/bash
# Create SMI devices (if not already created on host)
for i in $(seq 0 $((NUM_IB_PORTS - 1))); do
  rdma dev add smi${i} type SMI parent mlx5_${i} 2>/dev/null || true
done

# Start OpenSM
opensm -f /var/log/opensm.log &

# Wait for fabric to come up
sleep 10
ibstat
